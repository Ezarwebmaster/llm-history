## What happened
On August 13, 2026, DeepSeek released V4 Pro to general availability, building on its April preview. The release added flexible reasoning effort for V4 Pro and V4 Flash (low, high and max), native OpenAI Responses API support optimized for Codex, and availability in the app and on the web through "Expert Mode". The model is a mixture-of-experts design with 1.6 trillion total parameters and 49 billion active, released under the MIT license.

## Why it matters
General availability put a frontier-scale open-weight model into wider agent workflows, pairing it with the OpenAI API format so developers could adopt it with less friction.
