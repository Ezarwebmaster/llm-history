## What happened
On October 20, 2026, at PyTorch Conference North America, the Cloud Native Computing Foundation (CNCF) sandbox project llm-d—co-founded by Red Hat, IBM, Google Cloud, CoreWeave, and NVIDIA—released version 1.0. Designed to orchestrate open-source inference engines such as vLLM and SGLang across Kubernetes (container-orchestration) clusters on NVIDIA, AMD, and Intel GPUs as well as Google TPUs, v1.0 graduates its configuration API to stable status. It introduces multi-tenant quality of service (priority- and fairness-aware flow control), zero-downtime rolling upgrades, and session-aware routing for multi-turn agent workloads, alongside prefix-cache routing, tiered key-value (KV) cache offloading (storing reusable attention state in CPU memory or disk), and prefill-decode disaggregation (separating prompt processing from token generation).

## Why it matters
As language model serving shifted from chat to multi-step agents, llm-d v1.0 provided a vendor-neutral open-source control plane for running distributed inference in production.
