## What happened
On November 17, 2026, Microsoft AI released two coding models. Microsoft describes MAI Code 2 as aimed at multi-file implementation, deep debugging, interface work and reasoning across whole repositories. The smaller MAI Code 2 Flash targets high-volume tasks such as explanations, focused edits, routine fixes and rapid iteration. Both models became available in GitHub Copilot, while Flash also entered a limited-access preview in Microsoft Foundry.

## Why it matters
The release extended Microsoft's in-house model family into two coding tiers: one for longer repository tasks and another for frequent, narrower developer work.
