## What happened
OpenAI launched GPT-5.3-Codex on February 5, 2026 in the Codex app, command line, editor extension and web for paid ChatGPT plans. API access was still forthcoming at launch; the Responses API received `gpt-5.3-codex` on February 24, 2026. OpenAI described it as combining GPT-5.2-Codex's coding capabilities with GPT-5.2's reasoning and professional knowledge, and reported 25% faster operation for Codex users.

## Why it matters
The Codex model line broadened from software engineering toward work involving research, tools, spreadsheets and presentations. Users could steer the model during a running task without losing its context. This continued the longer-running work of GPT-5.2-Codex, while the smaller Codex-Spark preview that followed would emphasize rapid, targeted coding exchanges.
