## What happened
OpenAI's API deprecation records date the retirement of `code-davinci-001` to March 23, 2023, as part of the original Codex shutdown. Its status report already identified the model by name as part of the Codex beta in June 2022.

## Why it matters
The service records identify an earlier Davinci model in the coding API. Its retirement was shared with the Codex offering of `code-davinci-002` and with the Cushman models.
