## What happened
OpenAI announced that whisper-1, GPT-4o Transcribe, GPT-4o mini Transcribe and GPT-4o Transcribe Diarize would shut down on February 26, 2027. It recommended GPT-Live-Transcribe or GPT-Transcribe as replacements. The notice also scheduled the audio translations endpoint to close on the same date.

## Why it matters
Developers using the hosted transcription services received a migration deadline. This concerns OpenAI's API services; it does not withdraw the downloadable Whisper checkpoints that users can run on their own machines.
