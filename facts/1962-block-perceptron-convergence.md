## What happened
In the January 1962 issue of *Reviews of Modern Physics* (Vol. 34, No. 1, pp. 123–135), Cornell University mathematician H. D. Block published a mathematical exposition of Frank Rosenblatt's perceptron—an early neural network connecting sensory input units through association units to a threshold decision unit. Block formalized the simple perceptron's error-correction learning rule, which adjusts connection weights whenever the network misclassifies an example, and proved the perceptron convergence theorem: if a training set is linearly separable (divisible into two classes by a straight line or flat boundary), the update rule is guaranteed to find a separating set of weights in a finite number of steps.

## Why it matters
Block's analysis gave early neural network research a rigorous mathematical guarantee that simple error-driven weight updates converge whenever a linear boundary exists, anchoring later statistical learning theory.
