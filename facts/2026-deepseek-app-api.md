## What happened
DeepSeek made web search, file parsing and link reading available as built-in API tools for V4.1-Flash. DeepSeek's servers run the tools and assemble the material for the model. The release also made speech recognition and speech synthesis available as standalone services.

## Why it matters
An application could let users ask questions about an uploaded document or a linked page without building its own document parser or link reader.
