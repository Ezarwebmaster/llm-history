## What happened
On November 23, 2026, Z.ai released GLM-5.4 for GLM Coding Plan subscribers and its ZCode harness, with general API access and open weights planned after safety evaluations. Adapting the 750B-scale GLM-5 base model into what Z.ai calls a Loop Transformer, it runs a shared block of 28 layers twice per forward pass using gated progressive updates to keep activation values stable across iterations. It accepts text, images, video, and files over a 1-million-token context window with up to 128,000 output tokens.

## Why it matters
Instead of adding unique parameters, GLM-5.4 trades extra compute per pass for deeper reasoning, which Z.ai says matches 2T-to-3T-parameter models on generalized coding tasks spanning software engineering, games, and 3D design, though recursive thinking loops can slow complex responses.
