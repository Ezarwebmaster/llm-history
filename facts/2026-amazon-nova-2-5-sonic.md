## What happened
On October 5, 2026, AWS announced the general availability of Amazon Nova 2.5 Sonic, a speech-to-speech model: it takes spoken words in and answers out loud, rather than working only with text. It is built for real-time voice agents, with improved reasoning, instruction following and tool calling, so a support agent can look up an order, check return eligibility and start a return within one conversation. It speaks expressive voices in seven languages, and its context window holds roughly 256,000 tokens of conversation. It runs in Amazon Bedrock.

## Why it matters
Voice agents gain the same abilities as text agents, such as reasoning, longer context and tool use, narrowing the gap between speaking to a computer and typing to one.
