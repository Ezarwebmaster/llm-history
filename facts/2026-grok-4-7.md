## What happened
On September 21, 2026, SpaceXAI released Grok 4.7 for coding and knowledge work. It was available that day in Cursor, Grok Build, and the API. SpaceXAI says it uses a larger base model than Grok 4.6 and a longer training run on tasks that take many hours. Its launch table reports 46.3% on CursorBench 4.0, a test of longer coding jobs, and 37.6% on Terminal-Bench 4.0, a command-line coding test.

## Why it matters
It is SpaceXAI's current model for agents that write code and check their own work, though that same table still trails some rivals on long terminal tasks.
