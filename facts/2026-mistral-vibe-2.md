## What happened
Mistral released Vibe 2.0, an update to its terminal coding agent powered by the Devstral 2 model family. Users could create specialized subagents for tasks such as reviewing changes or generating tests, load reusable workflows through slash commands, and configure modes combining tools, permissions and behavior. Mistral also added multiple-choice clarification prompts for ambiguous requests and continuous updates to the command-line application.

## Why it matters
Coding assistants were becoming configurable work environments around language models. Vibe 2.0 let developers package recurring tasks and choose which tools and permissions an agent would use, while clarification prompts gave users a way to resolve uncertainty before execution.
