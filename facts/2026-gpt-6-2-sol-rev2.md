## What happened
On November 17, 2026, OpenAI released GPT-6.2 Sol (`gpt-6.2-sol`) as its efficient model for everyday coding, writing, and multi-step agentic workflows. Available at launch across ChatGPT Work, Codex, and the OpenAI API, it accepts text and image inputs, outputs text, and supports a 1,050,000-token context window (up to 922,000 input tokens and 128,000 output tokens). OpenAI's API documentation notes that tool calling uses the Responses API and that requests with reasoning effort set to `none` are rejected.

## Why it matters
OpenAI reports that GPT-6.2 Sol delivers stronger results while using fewer output tokens, improves by 5.3 points over GPT-6.1 Sol on GDPval v2, and comes within 0.5 points of GPT-6.2 Astra at maximum reasoning effort on FrontierCode 2.0, which grades whether changes to real codebases meet maintainers' merge standards.
