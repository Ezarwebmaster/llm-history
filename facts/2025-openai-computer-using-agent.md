## What happened
On January 23, 2025, OpenAI introduced Computer-Using Agent with Operator, a standalone browser product initially available to ChatGPT Pro users in the United States. The model used GPT-4o's visual abilities to interpret screenshots and choose actions such as clicks, typing, and scrolling. On March 11, OpenAI made the model available to select developers in the Responses API as `computer-use-preview`. Operator's capabilities were later integrated into ChatGPT agent mode on July 17.

## Why it matters
The model let software interact with ordinary buttons and text fields on websites that offered no dedicated programming interface. Operator packaged that ability in a browser for users, while the API preview let developers apply it to tasks such as data entry in their own applications.
