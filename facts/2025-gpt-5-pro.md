## What happened
OpenAI introduced GPT-5 pro to ChatGPT Pro subscribers on August 7, 2025, replacing o3-pro. It was a GPT-5 variant that spent more computation on difficult questions, including running reasoning in parallel. OpenAI positioned it for more comprehensive and accurate answers than ordinary GPT-5 reasoning.

The API release followed on October 6, 2025: developers could request `gpt-5-pro` through the Responses API. The model documentation describes a version of GPT-5 that uses more computation to think harder.

## Why it matters
The ChatGPT debut and developer availability were separate events nearly two months apart. Pro extended the computation spent answering a question within the GPT-5 family; it was not the next numbered flagship generation. Its launch made longer reasoning an explicit option for users willing to wait for harder problems.
