## What happened
OpenAI released GPT-5.2-Codex, a version of GPT-5.2 specialized for coding agents, across all Codex interfaces for paid ChatGPT users on December 18, 2025. The model reached the Responses API on January 14, 2026 as `gpt-5.2-codex`.

## Why it matters
OpenAI reported improvements in compaction, understanding long inputs and reliably calling tools. Building on Codex-Max, the model could carry the important parts of a long session forward as its working history was compressed, and use that context to keep iterating when plans changed or earlier attempts failed. OpenAI reported better performance on large code reorganizations, migrations and work in native Windows environments.
