## What happened
On February 16, 2023, OpenAI reported degraded performance for two API models, `code-davinci-002` and `text-davinci-002`, then marked the incident resolved the same day. The status log gives a dated record of both models in service after the March 2022 insertion rollout.

## Why it matters
OpenAI introduced `code-davinci-002` as the Codex model that could fill a gap in existing code using the lines on either side. `text-davinci-002` was the text model in the same rollout. OpenAI's deprecation table lists a March 2023 shutdown for `code-davinci-002` under Codex and a separate January 2024 shutdown under base GPT models.
