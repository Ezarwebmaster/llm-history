## What happened
On July 9, 2026, OpenAI launched the GPT-5.6 family for general availability, with Sol as its flagship model alongside the balanced Terra and efficient Luna variants. OpenAI's API model page identifies `gpt-5.6-sol` as the flagship for complex professional work, with a 1,050,000-token context window, up to 128,000 output tokens, adjustable reasoning effort, text and image input, and tool support including web search, code execution, computer use and MCP.

## Why it matters
GPT-5.6 Sol joined long-context reasoning, multimodal input and agent tools in one flagship model. Giving Sol its own record also separates it from the existing GPT-5.6 Luna timeline fact.
