## What happened
OpenAI introduced GPT-5-Codex, a version of GPT-5 further trained for software engineering. Training covered building projects, adding features and tests, debugging, large refactors and code review. OpenAI described it as adapting its reasoning time to the task, supporting both interactive sessions and longer independent work.

It launched as the default for Codex cloud tasks and code review, with developers able to select it in Codex CLI and the IDE extension. On September 23, OpenAI expanded access to API-key users through the Responses API only.

## Why it matters
The model applied coding-specific training after the general GPT-5 model's development. Its deployment across local and cloud tools made the same specialization available for pairing, delegated implementation and review. OpenAI recommended it for agentic coding rather than general-purpose use.
