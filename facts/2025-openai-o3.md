## What happened
OpenAI released o3 alongside o4-mini. In ChatGPT, o3 could search the web for information, run Python code to calculate results or analyze uploaded data, and work through visual details in images such as charts and diagrams. OpenAI trained it to decide when and how to use these capabilities and to combine them within one request.

## Why it matters
o3 extended the o1 series’ approach of working through a problem before answering. It could bring new evidence into that process, for example by finding data online, running a calculation on it, and using the result to support its answer.
