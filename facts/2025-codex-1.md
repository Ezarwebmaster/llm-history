## What happened
OpenAI introduced codex-1 as the model powering the research preview of Codex in ChatGPT, initially rolling out to Pro, Business and Enterprise users. It trained this version of o3 on real coding tasks with reinforcement learning, which uses feedback to improve how the model works through a task. The Codex product gave each task its own cloud environment with a copy of the repository and tools to edit files and run tests.

## Why it matters
The 2021 Codex API offered a GPT-3 descendant that generated code from instructions. With codex-1, an o3-based model could work through a repository task over several iterations, using Codex’s tools to test its changes before presenting them for human review.
