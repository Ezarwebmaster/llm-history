## What happened
On March 19, 2025, OpenAI released o1-pro, an o1 reasoning model that uses more computing work to answer difficult problems. This API model followed o1 pro mode, a version of o1 offered in ChatGPT Pro on December 5, 2024.

## Why it matters
The API release let developers use the more compute-intensive reasoning option in their own applications. OpenAI said the extra work aimed to improve reasoning and consistency, with the trade-off of longer answers to generate in ChatGPT.
