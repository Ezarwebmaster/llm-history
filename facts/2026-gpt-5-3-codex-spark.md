## What happened
On February 12, 2026, OpenAI released GPT-5.3-Codex-Spark as a research preview for ChatGPT Pro users in the latest Codex app, CLI and VS Code extension. API access was limited to a small set of design partners. OpenAI called it a smaller version of GPT-5.3-Codex. It launched with text-only input, a 128,000-token context window and separate preview usage limits.

## Why it matters
Spark added a complementary branch to Codex: quick, interactive edits alongside the main model's longer-running work. Served on Cerebras hardware, it generated over 1,000 tokens per second according to OpenAI. Its lightweight default behavior favored targeted changes and did not automatically run tests unless asked. The preview explored how shorter waits could change collaboration, rather than simply replacing the full GPT-5.3-Codex model.
