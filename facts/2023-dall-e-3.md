## What happened
OpenAI unveiled DALL·E 3 on September 20, 2023 as a research preview. Its researchers used a separate model to write more descriptive captions for images used in training. OpenAI reported that training with those captions helped DALL·E 3 follow detailed requests more closely.

OpenAI announced availability in ChatGPT Plus and Enterprise on October 19, with developer API access following at DevDay on November 6.

## Why it matters
The work showed how the language paired with training images can improve which details a generator retains from a prompt. In ChatGPT, users could describe an idea, let the language model turn it into a detailed image prompt, then request changes in the same conversation.
