## What happened
On November 15, 1961, MIT researchers demonstrated the Compatible Time-Sharing System (CTSS), the first practical time-sharing system that allowed multiple users to log into a single computer and run programs simultaneously through terminals. The system introduced passwords and provided each user with a dedicated time slice.

## Why it matters
CTSS pioneered interactive computing and laid the groundwork for modern multi-user operating systems, influencing the development of subsequent time-sharing systems like Multics and eventually Unix.
