## What happened
OpenAI announced an improved version of Codex and began providing private beta access through its API. The original Codex was descended from GPT-3 and trained on natural language and publicly available source code. OpenAI said it was strongest in Python and could work in more than a dozen programming languages. Codex already powered the GitHub Copilot preview.

## Why it matters
The API gave developers a way to use a code-generation model in their own tools, including interfaces that turn written instructions into calls to existing software. OpenAI deprecated the original Codex models in March 2023 and later used the Codex name for its cloud software engineering agent.
