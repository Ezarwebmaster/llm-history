## What happened
OpenAI launched o3-pro on June 10, 2025, in the API and for Pro and Team users in ChatGPT. It used the same underlying model as o3, which launched on April 16. The pro version spent more computing work on each request before answering. OpenAI said that some API requests could take several minutes.

## Why it matters
The extra work targeted hard questions where a dependable answer justified a longer wait. OpenAI reported that expert reviewers preferred o3-pro across the categories it tested, including science and programming. It also tested repeatability by counting a question as solved only if all four attempts were correct.
