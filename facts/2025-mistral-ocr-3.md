## What happened
Mistral made OCR 3 available through its API and Document AI Playground. The model extracts text and embedded images, with Markdown output and reconstructed table structure. Mistral reported improvements over OCR 2 for handwriting, forms and degraded scans.

## Why it matters
Language applications need readable source material before they can search archives or answer questions about documents. Preserving tables and layout helps keep relationships between values intact, rather than feeding an assistant a jumble of extracted words. The release strengthened this input stage of document and agent workflows.
